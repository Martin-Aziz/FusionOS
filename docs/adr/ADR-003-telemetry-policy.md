# ADR-003: Opt-In Telemetry Policy

## Status

Accepted

## Context

TriOS aims to be privacy-first and trust-oriented while still requiring quality signals for compatibility and stability improvements.

## Decision

Telemetry remains opt-in by default. Telemetry ingestion APIs exist, but activation is user-controlled.

## Consequences

- Positive: aligns with privacy-centric product position.
- Negative: lower passive data volume, requiring stronger community reporting loops.
